# Architecture

この章では、ABR Geocoderのアーキテクチャ設計について解説します。全体像からレイヤー構成、コンポーネント、クラス設計、依存性注入まで、システムの構造を理解するための情報を提供します。

## 各セクション

- **Overview**: システムの高レベル構成とデータフロー
- **Clean Architecture**: レイヤー責務と依存関係の方向性
- **Components**: ディレクトリ別の役割とファイル構成
- **Classes**: 主要クラスの設計原則と実装パターン
- **Dependency Injection**: DIの基礎から実装方法、テスタビリティ向上まで
