# ABR Geocoder 内部仕様

このドキュメントは、ABR Geocoder の内部アーキテクチャ、設計思想、並列処理、そして SQLite を起点に生成されるキャッシュ（ABRG2 バイナリ辞書）の仕様をまとめたものです。公開前提の日本語ドキュメントであり、Mermaid 図を用いて構造を可視化しています。

主対象:

- コア開発者・レビュアー（内部仕様の把握）
- 運用担当（キャッシュ再生成や互換性の判断）
- 外部コントリビュータ（拡張/改修の際の参照）

このドキュメントの読み方:

- Architecture でシステム全体像とクリーンアーキテクチャ/DI 方針を把握
- Geocoding で探索戦略・並列化・ABRG2 仕様の詳細を把握
- Classes/Utilities で要素技術の API と責務を把握
- Operations/Troubleshooting で実運用の要点を確認
