# 入門ガイド（Node.js 中級者向け）

対象読者:

- Node.js/TypeScript は書けるが、アルゴリズムやデータ構造に自信がない方

この章では、本プロジェクトで重要な「トライ木（Trie）」「バイナリファイル」「ハッシュと重複排除」「ストリーム/Buffer」「Worker による並列処理」を、実装の背景から丁寧に解説します。実コードへ近いサンプルや図を多用し、概念→実装の順で学べる構成にしています。

学び方の順序（推奨）:

1) Trie と探索の考え方
2) バイナリファイルの基礎
3) ハッシュと重複排除
4) ストリームと Buffer
5) 並列処理と Worker
