# Troubleshooting

- ヘッダー不正（`magic!=abrg` / `version<2.2`）
  - キャッシュ破損の可能性。該当ファイル削除→再生成
- 読み出し中の例外（オフセット異常/サイズ不一致）
  - 途中中断などで破損。再生成
- メモリ不足
  - 共有メモリで辞書を載せるため、起動オプション/ハード制約を確認
- 結果が期待と違う
  - 正規化規則（漢数字, 旧字体, 記号）を確認
  - スコアリングは入力長/一致割合/曖昧回数/区分別に依存（`geocode-result-transform.ts`）
- 速度劣化
  - キャッシュが古い/分割不足。`oaza-cho` は LG ごとに分割されているか確認
  - ワーカースレッド数と `maxTasksPerWorker` のバランス
